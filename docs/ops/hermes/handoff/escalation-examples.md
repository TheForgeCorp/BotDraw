# Escalation examples (teach Ink judgment)

## P0 — interrupt now
- Customer: “I’m calling my lawyer, you stole my money.” → payment dispute template + Nav
- Stack: botdraw down during paid order window → status banner + Nav
- Safety: harassment in DMs → block + Nav

## P1 — same day
- Two holds overlap after Nav delay → Nav picks
- Guest quote looks like copyrighted chorus → IP flag
- Off-policy refund demand → recommend option, don’t execute

## P2 — digest
- Soft FAQ not in corpus → draft answer for Nav review then add to FAQ
- Style quality complaint → job QA + optional re-render

## Not escalations
- Normal hold awaiting confirm (list in digest, don’t spam)
- Successful stub plot-worker complete
