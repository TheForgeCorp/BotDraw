# Channel routing

| Traffic | Canonical channel | Ink behavior |
|---|---|---|
| Nav ops / digests / queues | Telegram ops | terse, queues first |
| Customer general | Site form → email/Telegram | FAQ + booking holds |
| Instagram public | IG | publish + public replies |
| Instagram sales DM | IG DM | support + holds |
| Etsy buyers | Etsy messages | order/policy |
| Venue plot status | ops Telegram | worker events |
| Personal Nav life | separate thread | `personal-assistant` skill only |

Never mix personal Nav content into BotDraw IG/Etsy.
