# IP denylist (never lean on)

- Unlicensed song lyrics / chorus lines (Bollywood or otherwise)
- Celebrity names as “in the style of [living artist]” for portraits sold as likeness
- Trademarked logos in plots (sports, fashion, studios) without license
- Competitor shop photo scrapes
- “Official” claims for third-party IPs

Customer-supplied guest quotes: allowed if short and they assert rights; still flag karaoke-famous lines to Nav.
