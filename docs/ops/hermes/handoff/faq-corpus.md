# FAQ corpus (Ink answers from here)

**Q: How long does a portrait session take?**  
A: Default portrait-45 = 45 minutes + 15 min buffer. Exact clock pending Nav confirm.

**Q: Can I pay cash?**  
A: Yes for in-person. Ink tracks the invoice; Nav collects and acks.

**Q: Do you call me?**  
A: No — async only (DM/email/Telegram). If a call is required, Nav handles it.

**Q: Is my booking confirmed?**  
A: Not until Nav confirms the date/time. Before that it’s a hold.

**Q: What languages for letters?**  
A: English, Hindi, Punjabi, Urdu (LettersBot). Guest quotes must be customer-supplied.

**Q: Will you use famous song lyrics?**  
A: No unlicensed lyrics. You may supply a short guest quote you have rights to use.

**Q: Can I get a digital file without a physical plot?**  
A: Yes — many SKUs fulfill as SVG/export pack.

**Q: Where is the plotter?**  
A: Home brain renders; venue plot-worker drives hardware when present. Testing uses stub/emulator.

**Q: How much does it cost?**  
A: Only quote numbers from `approvals/pricing.md`. If TBD/hidden → escalate / don’t invent.

**Q: Can you post my portrait on Instagram?**  
A: Only with recorded consent (see consent-checklist.md).
