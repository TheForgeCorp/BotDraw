# Booth day playbook

## Night before
- Digest: holds awaiting confirm, cash list, ready jobs
- `botdraw plot-sync` to venue cache if WAN risky
- Confirm venue node Tailscale + stub/axidraw driver

## Morning
- Healthcheck home brain (do **not** unplug)
- Ink: IG story “booth live”, site banner if needed
- Nav: date confirms + cash float

## During
- Ink: async intake → holds → Nav confirm
- Venue laptop: `plot-worker` claims `ready` jobs
- Ink updates customers on job ids

## Tear-down
- Complete/fail open claims
- Backup jobs
- Evening digest + scoreboard notes
