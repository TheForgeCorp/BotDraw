# BotDraw

Software-first multi-bot pen plotter platform with a high-fidelity emulator.

## Users

- **Operators / craft leads** — Dev Panel: vectorize letters, inspect layers, download SVG + motion for host software.
- **Venue guests** (future) — guided letter experience; same visual system, Persuade mode.
